# Room Node PCBs

Multi-function home-IoT sensor/control nodes — **one per room**: LED control, BLE tracking, human presence, temperature/humidity, air quality. ESPHome (ESP-IDF) firmware, in-house fab + pick-and-place friendly, 2-layer JLCPCB-compatible.

**[Documentation site (GitHub Pages)](https://askalice.github.io/room-node-pcbs/)** · [Component manifest](docs/component-manifest.md) · [Datasheets](docs/datasheets/README.md) · [STEP models](models/README.md) · [Firmware](firmware/)

## Fabrication (JLCPCB-ready)

Each board has a complete fab package — gerbers, drill, pick-and-place CSV, BOM CSV:

- `fab/roomnode-s3_jlcpcb.zip` · `fab/roomnode-c6_jlcpcb.zip` · `fab/roomnode-c3-mini_jlcpcb.zip` · `fab/airnode-s3_jlcpcb.zip`

Zips are rebuilt and committed by CI; unzipped outputs live in `fab/<board>/`.

## Design notes

- **Hardware-as-code**: boards are generated by `boards/<name>/build.py` using `tools/kicad_gen.py`; regenerate with `python3 build.py`, then `python3 tools/add_3d_models.py` binds STEP 3D models.
- **RF layout**: official Espressif module land patterns; antenna overhangs board edge; all-layer antenna keep-out rule areas (verified programmatically: zero copper/vias/pads inside).
- **Power**: USB-C (TYPE-C-31-M-12) with 5.1kΩ CC1/CC2 pull-downs, USBLC6 ESD, AMS1117-3.3 / ME6211 regulators.
- **Assembly**: every SMD part carries an LCSC part number in the footprint; datasheets in `docs/datasheets/` (fetch via `tools/fetch-assets.sh`); STEP models in `models/` and `boards/<name>/models/`.
- **Nets/DRC**: full net assignment (GND/+5V/+3V3/signals), JLCPCB 2-layer design rules, mask+paste layers on all pads.
