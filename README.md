# Room Node PCBs

Multi-function ESP32 room-sensor nodes — one per room. Presence, climate, air quality, light, BLE tracking and LED control, designed for [ESPHome](https://esphome.io) / Home Assistant (Matter · Thread · Zigbee · BLE · WiFi).

All boards are 2-layer, hand-assembly / in-house pick-and-place friendly (0603 passives, SOT-23/SOT-223, no BGA/QFN under module), powered by USB-C (16-pin mid-mount, C165948) with 5.1k CC pull-downs and USBLC6 ESD. Every SMD part has an in-repo datasheet ([docs/datasheets/](docs/datasheets/)) and a KiCad 3D model.

> Hardware-as-code: every board is generated by `boards/<board>/build.py` (KiCad 10 format), rendered with `kicad-cli pcb render` (raytraced, `--floor --perspective`), and packaged for JLCPCB by CI.

## Fabrication

Each `fab/<board>_jlcpcb.zip` contains gerbers + drill + pick-and-place CSV + BOM CSV — upload straight to JLCPCB (or your in-house line). Design sources are `boards/<board>/build.py`; regenerate everything with:

```bash
python3 boards/<board>/build.py        # KiCad files
python3 tools/add_3d_models.py         # attach STEP models
bash tools/produce_all.sh              # raytraced renders + fab zips
```

Rendered outputs (raytraced PNGs, routing/schematic exports, fab zips) are produced and committed by CI (`ci-pending/` — see its README for one-step activation).
